## Instrucciones
1. Clona el repositorio
2. Descarga WordPress desde [wordpress.org](https://wordpress.org)
3. Coloca los archivos de WordPress en la raíz del proyecto
4. Coloca `wp-content` desde este repositorio
5. Configura la base de datos `camcom.sql`
6. Configura `wp-config.php` con tus datos locales
